# astrea-discord-site

Site statique pour le serveur Discord Astréa.

Déployé sur GitHub Pages (branch: main). Pour modifier :

1. Clone le repo
   ```bash
   git clone https://github.com/Astra-boop15/astrea-discord-site.git
   cd astrea-discord-site
   ```

2. Modifie les fichiers (index.html, about.html, rules.html, staff.html, styles.css)

3. Commit & push
   ```bash
   git add .
   git commit -m "Mise à jour du site"
   git push
   ```

Remarques :
- Remplace `assets/logo.png` et les avatars par tes images (push dans `assets/`).
- Pour la couleur d'accent, modifie la variable `--accent` dans `styles.css`.
- Si tu veux que je déploie la page GitHub Pages, active-la dans Settings → Pages en sélectionnant la branche `main` et le dossier `/ (root)`.
